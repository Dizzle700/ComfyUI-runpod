02

Соберите и опубликуйте image

GitHub установит зависимости во время сборки, до запуска вашего Pod.

  1. Откройте Actions → Build RunPod image → Run workflow.
  2. В поле version укажите v1.0.0 и запустите workflow. Для каждой новой публикации используйте новый номер.
  3. Дождитесь успешного завершения всех шагов. В Summary появится имя опубликованного image.
  4. Откройте GitHub-пакет comfyui-runpod → Package settings → Change visibility → Public. Тогда RunPod сможет скачать его без отдельного токена.
Открыть Actions Пакеты GitHub
Имя image · после успешной публикации
ghcr.io/dizzle700/comfyui-runpod:v1.0.0
Сначала дождитесь публикации. Локальный образ на вашем компьютере ещё не доступен RunPod. Первая сборка скачивает CUDA-базу и устанавливает пакеты; запуск Pod использует уже готовый image.

GitHub сам выдаёт workflow временный GITHUB_TOKEN. Для приватного пакета вместо Public добавьте GHCR credentials в настройках RunPod. Без номера версии ручной запуск публикует только тег sha-<SHA>.

Собрать image


Проверить контейнер на CPU


Проверка запускает ComfyUI на CPU, проверяет узлы Krea/Qwen, авторизацию API, сохранность файлов и повторный старт. Веса заменены временными заглушками. Генерация на GPU этим тестом не проверяется.




Обновления и дополнительные custom nodes


  1. Для обновления ComfyUI / Manager измените SHA COMFY_COMMIT / MANAGER_COMMIT в Dockerfile.
  2. Добавляйте постоянные custom nodes и их зависимости в сборку до сохранения .runpod-setup.json.
  3. Опубликуйте новый тег image, затем пересоздайте Pod с тем же network volume.


Флаги --update и --reinstall для готового образа предлагают пересборку. Узлы, установленные через панель / Manager в работающем контейнере, исчезнут при его пересоздании; изменение закреплённых пакетов может остановить следующий запуск проверкой окружения.


База закреплена digest, ComfyUI и Manager — Git SHA. Python-пакеты зафиксированы внутри построенного image; новая сборка может получить другие допустимые версии транзитивных зависимостей. Для запуска точно того же image используйте ghcr.io/…@sha256:… из вывода публикации.




Если что-то не открылось


RunPod не может скачать image
Проверьте успешный workflow, точное имя в Summary и видимость Public у GitHub-пакета. Приватный пакет требует registry credentials в RunPod.


Панель не запускается
Проверьте PANEL_USER и PANEL_PASS, порт 7860 и /workspace/runpod_startup.log.


Шаблон показывает ready: false
Если есть missing_models, дождитесь загрузки и посмотрите template-download.log. Если есть missing_nodes, добавьте нужные узлы в image. Если ComfyUI не отвечает, посмотрите comfyui.log. При необходимости обновите UI или перезапустите ComfyUI из панели.


Шаблон содержит MarkdownNote
Неисполняемые заметки Note / MarkdownNote удаляются при экспорте API JSON. В визуальном workflow они остаются. Другие custom nodes не удаляются.
