Развёртывание ComfyUI-runpod на RunPod

Актуальная инструкция по запуску ускоренного контейнера с Control Panel, серверной вкладкой «📦 Пакетная генерация», hf-xet и aria2c.

💡 Нажмите в любое место блока кода или подсвеченного поля, чтобы мгновенно скопировать текст

Способ 1: Готовый Docker Image (GHCR) Рекомендуемый

Самый быстрый и стабильный вариант: старт контейнера за ~10–15 секунд без git clone и pip install. Код ComfyUI работает из /opt/ComfyUI (не тормозит на Network Volume), байткод .pyc и aria2c уже запечены в образ, а модели, output и настройки сохраняются в /workspace/ComfyUI.

Шаг 1. Отправка изменений в GitHub и сборка образа

  1. Закоммитьте и отправьте изменения в ветку main (включая comfy_batch_engine.py, faq/templates_models.db и обновлённые скрипты).
  2. В GitHub откройте Actions → Build RunPod image → Run workflow и укажите тег релиза, например v1.1.0.
  3. Дождитесь завершения workflow — образ появится в GHCR под именем ghcr.io/dizzle700/comfyui-runpod:v1.1.0.

Шаг 2. Параметры RunPod Template / Pod

Поле в RunPod Значение
Container Image ghcr.io/dizzle700/comfyui-runpod:v1.1.0
Container Start Command Оставить пустым — запуск уже настроен в ENTRYPOINT образа
Volume Mount Path /workspace (рекомендуется Network Volume для сохранения моделей)
Expose HTTP Ports 7860,8188
Expose TCP Ports 22 (опционально, если нужен SSH)

Шаг 3. Environment Variables (переменные окружения)

PANEL_USER={{ RUNPOD_SECRET_comfy_panel_user }}
PANEL_PASS={{ RUNPOD_SECRET_comfy_panel_password }}
COMFY_TEMPLATE_IDS=89,93,94
COMFY_TEMPLATE_DOWNLOAD_WORKERS=4
AUTO_START_COMFY=1
HF_TOKEN={{ RUNPOD_SECRET_huggingface_token }}
CIVITAI_API_TOKEN={{ RUNPOD_SECRET_civitai_token }}
Дополнительные флаги ускорения и диагностики:
• RUNPOD_BASE_SERVICES=0 — отключить фоновый Jupyter/SSH из базового образа (ещё быстрее старт и меньше RAM).
• COMFY_VERIFY_ON_START=1 — принудительно включить полную проверку Python-пакетов и импортов при старте (по умолчанию 0 для мгновенного запуска).
• COMFY_TEMPLATE_DOWNLOAD_WORKERS=4 — количество параллельных загрузок моделей (доступно от 1 до 8).

Способ 2: Базовый образ RunPod + Start Command Без сборки Docker

Подходит, если нужно быстро проверить изменения после git push, не дожидаясь сборки образа в GitHub Actions.

Поле в RunPod Значение
Container Image runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404
Expose HTTP Ports 7860,8188
Обязательные Secrets PANEL_USER и PANEL_PASS (плюс HF_TOKEN / CIVITAI_API_TOKEN при необходимости)

Команда запуска с фоновой загрузкой шаблонов (89, 93, 94)

bash -lc 'cd /workspace && if [ ! -d runpod-scripts/.git ]; then git clone --depth 1 https://github.com/Dizzle700/ComfyUI-runpod.git runpod-scripts; elif [ "${COMFY_UPDATE_ON_START:-0}" = 1 ]; then git -C runpod-scripts pull --ff-only; fi && bash runpod-scripts/runpod_startup.sh --templates 89,93,94'

Обычный запуск без предзагрузки моделей

bash -lc 'cd /workspace && if [ ! -d runpod-scripts/.git ]; then git clone --depth 1 https://github.com/Dizzle700/ComfyUI-runpod.git runpod-scripts; elif [ "${COMFY_UPDATE_ON_START:-0}" = 1 ]; then git -C runpod-scripts pull --ff-only; fi && bash runpod-scripts/runpod_startup.sh'

Однократное обновление скриптов, ComfyUI и зависимостей

COMFY_UPDATE_ON_START=1 bash -lc 'cd /workspace && if [ ! -d runpod-scripts/.git ]; then git clone --depth 1 https://github.com/Dizzle700/ComfyUI-runpod.git runpod-scripts; else git -C runpod-scripts pull --ff-only; fi && bash runpod-scripts/runpod_startup.sh --templates 89,93,94'

Работа после запуска Pod

  • Панель управления (Gradio + Batch Runner): https://POD_ID-7860.proxy.runpod.net
  • Интерфейс и API ComfyUI: https://POD_ID-8188.proxy.runpod.net

Использование вкладки «📦 Пакетная генерация»

  1. Откройте панель управления на порту 7860 и перейдите во вкладку 📦 Пакетная генерация.
  2. Выберите готовый API Workflow из выпадающего списка (шаблоны из COMFY_TEMPLATE_IDS появляются сразу с индикатором готовности моделей 🟢 / ⏳) или загрузите свой .json (API Format).
  3. Убедитесь, что целевой узел промпта определился автоматически (значок ⭐).
  4. Загрузите файл .txt с промптами или вставьте их в текстовое поле (по одному промпту на строку) и нажмите 🚀 Запустить пакет.
  5. Генерация идёт локально на сервере (127.0.0.1:8188) — браузер можно закрыть. Готовые изображения скачиваются архивом во вкладке 🎞️ Output.

Проверка статуса шаблонов через API

curl -u "$PANEL_USER:$PANEL_PASS" https://POD_ID-7860.proxy.runpod.net/template-apis
Важно: пароль PANEL_USER / PANEL_PASS защищает порт 7860 (панель, терминал и /template-apis). Порт 8188 открывает стандартный ComfyUI без авторизации — для приватного доступа не публикуйте 8188 через HTTP Proxy, используйте SSH-туннель.
