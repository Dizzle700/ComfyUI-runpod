Каталог Шаблонов и Инструкция RunPod

Готовые команды развёртывания воркфлоу ComfyUI. Кликните на любой блок команды, чтобы скопировать её в буфер обмена для запуска в RunPod!

★ Инструкция: Запуск ComfyUI на RunPod за 4 шага

Шаг 01

Создание Pod в RunPod

Выберите GPU (RTX 4090 / RTX 5090 / A100) и задайте настройки шаблона:

  • Image: runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404
  • Volume: 80–120 GB на /workspace
  • Container Disk: 20–30 GB
Шаг 02

Открытие HTTP портов

В настройках Pod в поле HTTP Ports обязательно укажите:

7860,8188
  • 7860: Панель управления с авторизацией
  • 8188: Сам сервер ComfyUI
Шаг 03

Переменные окружения (Env)

Задайте обязательные параметры в блоке Environment Variables:

  • PANEL_USER=admin
  • PANEL_PASS=ваш_надежный_пароль
  • HF_TOKEN=hf_... (опционально)
Шаг 04

Выбор команды и запуск

Выберите нужный шаблон из каталога ниже, кликните по его блоку команды и вставьте её в поле Docker Command при деплое Pod.

✓ Модели начнут скачиваться в фоне автоматически!

💡
Как подключиться после старта пода: Перейдите в веб-интерфейс по ссылке https://<POD_ID>-7860.proxy.runpod.net (введите логин и пароль из PANEL_USER / PANEL_PASS). Панель покажет прогресс скачивания моделей в реальном времени, позволит перезапускать ComfyUI и работать в терминале.
